# Big Sky ROI

**Wall Street–grade investment research for Amazon product capital allocation.**

Live: [https://bigskyroi.com](https://bigskyroi.com)

## Stack

- Static site in `public/`
- Cloudflare Worker (`workers/site.js`) for HTTPS, www→apex, sitemap Content-Type
- Deploy: `npm run deploy`

## Local

```bash
npm install
npm run preview   # http://localhost:8892
# or
npm run dev       # wrangler dev
```
